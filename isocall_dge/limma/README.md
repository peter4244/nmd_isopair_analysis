# isocall_dge/limma/

Limma-voom transcript-level differential expression results from the isocall pipeline.

## Layout

- `pete/` — Pete Castaldi's limma run, dated 2026.3.1.
  Files (gitignored):
  - `nmd_isocall_dge_{at,dd,ddali,do,fb,mv}_2026.3.1.csv` — per-cell-type DGE (`logFC`, `P.Value`, `adj.P.Val`, …)
  - `dgelist_isocall_2026.3.1.rds` / `dielist_isocall_2026.3.1.rds` — DGEList / DIE-list serialized R objects
  - `*_filtered*.csv` — filtered subsets used by downstream isopair analyses
- `yul/` — Yul's parallel limma run, dated 2026.3.3.
  Files (gitignored): `nmd_dge_{at,dd,ddali,do,fb,mv}_2026.3.3.csv`

## Generated by

`code/isocall_limma_dge_fullmodel_2026.3.1.Rmd` (or the analyst's local equivalent for the yul/ subdir).

## Why gitignored

CSVs are 22–41 MB each and serialize R objects can reach ~44 MB. They're regenerable from the count matrix + sample metadata, so they live on disk but stay out of git history (matches the existing pattern for `longread_dge/*.csv` and `shortread_dge/*.csv`).
