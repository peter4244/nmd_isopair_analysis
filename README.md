# NMD Inhibition Effects on Isoform Expression

This repository contains analysis code for studying the effects of Nonsense-Mediated Decay (NMD) inhibition on transcript isoform expression patterns across multiple lung cell types using long-read (PacBio) RNA sequencing data.

## Project Overview

This project investigates how NMD pathway inhibition (using SMG1 inhibitor treatment) affects:
- Transcript isoform diversity per gene
- Dominant isoform prevalence
- Expression patterns of NMD-targeted transcripts
- Cell-type specificity of these patterns
- The fraction of transcriptional output devoted to NMD-targeted transcripts

## Study Design

### Cell Types
- **AT** (AT2) - Alveolar Type 2 cells
- **DD** - Differentiated Cells
- **DD_ALI** - Differentiated Cells at Air-Liquid Interface
- **DO** - Donor Cells (cultured at ALI)
- **FB** - Fibroblasts
- **MV** - Microvascular cells

### Treatments
- **DMSO** - Vehicle control (NMD active)
- **Smg1i** - SMG1 inhibitor (NMD inhibited)

### Sample Size
- 38 total samples (19 DMSO + 19 Smg1i)
- 6 cell types with biological replicates

## Key Scripts

### Main Analysis

**`code/interpret_isoform_patterns_2026.1.3.Rmd`**

The primary analysis script that:
1. Loads normalized transcript counts from a DGEList object (edgeR)
2. Calculates isoform proportions (% of gene expression per transcript)
3. Applies abundance filtering (≥0.25 CPM threshold)
4. Addresses five research questions (Q1-Q5)
5. Generates visualizations and summary tables
6. Exports results as TSV files

**Configuration:** All file paths and parameters are configurable at the top of the script (lines 19-77). Edit the `DATE_STAMP` variable and file paths to match your system.

### Helper Scripts

**`code/create_isoform_filter_dictionary.R`**
- Creates the abundance filter dictionary
- Filters transcripts to those with ≥0.25 CPM in at least one sample per treatment/cell type
- Required input for the main analysis script

## Research Questions

### Q1: Isoforms Per Gene
**Question:** Does NMD inhibition reveal more isoforms per gene?

**Method:** Count detected isoforms (normalized CPM > 0) per gene in DMSO vs Smg1i conditions

**Key Finding:** NMD inhibition increases detected isoforms per gene, with the majority of genes showing increased isoform diversity

### Q2: Dominant Isoforms
**Question:** How common are dominant isoforms (>50% of gene expression)?

**Method:** For genes with 3+ isoforms, identify if one isoform consistently accounts for >50% expression across all samples

**Key Finding:** Dominant isoforms are present in ~60-70% of multi-isoform genes; NMD inhibition slightly reduces this prevalence

### Q3: Baseline Proportions of NMD-Responsive Transcripts
**Question:** For NMD-responsive transcripts (upregulated with Smg1i), what were their baseline DMSO proportions?

**Method:** Extract DMSO proportions for transcripts with logFC > 0 and adj.P.Val < 0.05

**Key Finding:** NMD-targeted transcripts are predominantly minor isoforms at baseline (median proportion <0.1), with many having zero expression in DMSO

### Q4: Cell-Type Specificity
**Question:** Are isoform patterns consistent or cell-type-specific?

**Method:** Compare Q1-Q3 metrics across all cell types

**Key Finding:** Patterns are largely consistent across cell types, with low coefficient of variation for key metrics

### Q5: Transcriptional Output Devoted to NMD
**Question:** What proportion of transcriptional output is devoted to producing NMD-targeted transcripts?

**Method:** Using Smg1i data (NMD off), calculate percentage of gene/cell-type expression from NMD-responsive isoforms

**Key Finding:**
- Gene level: Genes with NMD-responsive isoforms devote ~30-40% of their output to NMD targets
- Genome-wide: ~5-8% of total cellular transcriptional output goes to NMD-targeted transcripts

## Data Analysis Approach

### Normalization
All analyses use **TMM-normalized CPM** values from the DGEList object, ensuring:
- Library size normalization across samples
- Consistency with differential expression analysis (limma-voom)
- Proper handling of compositional differences

### Abundance Filtering
To focus on reliably detected isoforms:
- **Threshold:** ≥0.25 CPM in at least one sample
- **Scope:** Within each cell type/treatment group
- **Rationale:** Retains ~98% of statistically significant isoforms while removing low-abundance noise

### Isoform Proportion Calculation
For each transcript in each sample:
```
isoform_proportion = transcript_CPM / sum(all_isoforms_CPM_for_gene)
```
Proportions sum to 1.0 for each gene within each sample.

## Data Formats

### DGE Results (longread_dge/)
CSV files with differential expression results:
- `txid` - Transcript ID (PB.* or ENST*)
- `logFC` - Log2 fold change (Smg1i vs DMSO)
- `adj.P.Val` - FDR-adjusted p-value
- `hgnc_id` - Gene ID
- Other limma-voom output columns

### Output TSV Files
Tab-separated files with analysis results, loadable via:
```r
library(readr)
data <- read_tsv("tmp/isoform_interpretation_q1_*.tsv")
```
