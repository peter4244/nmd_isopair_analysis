# Superseded — this is not the analysis code for the paper

The reproduction package for **Leshem et al., _Long Read RNA Sequencing in Primary Lung Cell Types
Reveals Principles of Nonsense-Mediated Decay_** is
**[peter4244/nmd_lung_longread_reproduction](https://github.com/peter4244/nmd_lung_longread_reproduction)**.

Go there to reproduce anything in the paper. It is the curated code, it names the Zenodo
source-data record the analyses start from, and its `REPRODUCTION.md` runs the chain end to end.

## What this repository is

The earlier working tree, kept for the record. **Its numbers are not the paper's.** The study
design it was built around is a different one — six cell types and 38 samples here, against the
four cell types (AT2, LAE, FB, MV) and 26 samples the manuscript reports. Nothing in it has been
kept in step with the published analysis.

It remains public and otherwise unchanged because it carries a Zenodo DOI,
[10.5281/zenodo.21539734](https://doi.org/10.5281/zenodo.21539734), which has already been cited.
Deleting a citable record is worse than labelling it.
