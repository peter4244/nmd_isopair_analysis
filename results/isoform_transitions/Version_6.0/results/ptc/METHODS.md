# PTC Analysis Methods

## Overview

These analyses investigate whether premature termination codons (PTCs) predict NMD responsiveness (Smg1i upregulation) among expressed isoforms in lung cell lines. Five complementary scripts address the question from different angles: isoform-level PTC computation, association testing, logFC distributions, systematic signal exploration, and pair-level analysis within the isoform transition framework.

## PTC Definition

PTCs are identified using the canonical 50-nucleotide rule: a stop codon is classified as premature if it is located >50 nucleotides upstream of the last exon-exon junction (EJC). This threshold is the established criterion for NMD substrate recognition in mammalian cells.

### Coordinate Computation

PTC distance is computed in mRNA space:

1. Exons are ordered biologically (5' to 3'), accounting for strand orientation
2. Cumulative mRNA positions are calculated from ordered exon lengths
3. The stop codon's mRNA position is determined by identifying its containing exon and computing the offset
4. PTC distance = last_EJC_position - stop_codon_position (in mRNA coordinates)

**Strand handling:**
- (+) strand: stop codon at `cds_stop`, exons ordered by ascending `start`
- (-) strand: stop codon at `cds_start`, exons ordered by descending `start`

Single-exon transcripts are classified as non-PTC (no EJCs possible).

### Additional PTC Features

- `n_downstream_ejcs`: number of exon-exon junctions downstream of the stop codon (more EJCs = stronger NMD trigger)
- `stop_in_last_exon`: whether the stop codon resides in the last exon (expected for normal transcripts)
- `is_gencode` / `is_novel`: isoform source (ENST prefix = GENCODE, PB. prefix = PacBio IsoSeq)

## Validation Against GENCODE NMD Biotype

Computed PTC status was cross-tabulated against GENCODE's `nonsense_mediated_decay` transcript biotype annotation for all GENCODE (ENST) isoforms with both annotations available. This serves as external validation of the PTC computation pipeline.

## CDS Sources

CDS annotations come from two sources:
- **GENCODE**: reference transcript annotations (ENST isoforms)
- **SQANTI**: CDS predictions for PacBio novel isoforms, generated by SQANTI3's ORF prediction

Both are stored in `isoform_cds_metadata.rds` (Script core/04).

## Isoform Source Stratification

All analyses stratify by isoform source (GENCODE vs PacBio) to assess whether PTC predictions are more reliable for reference-annotated isoforms. PacBio novel isoforms rely on SQANTI ORF predictions, which may be less accurate than curated GENCODE CDS annotations.

## Statistical Tests

### Fisher's Exact Test
Used for 2x2 contingency tables (PTC x NMD responsiveness, biotype x NMD responsiveness). Reports odds ratio with 95% CI.

### Logistic Regression
Models NMD responsiveness ~ log(PTC distance) to test for continuous dose-response relationships.

### Wilcoxon Rank-Sum Test
Compares logFC distributions between PTC+ and PTC- isoforms. Used throughout the logFC distribution and signal exploration analyses.

### Spearman Correlation
Tests for monotonic relationships between PTC distance and NMD responsiveness rate, and between logFC quantile and PTC enrichment.

### McNemar's Test
Tests for asymmetry in PTC status within dominant-comparator pairs.

### Fixed-Effects Meta-Analysis
Inverse-variance weighted pooling of log-odds ratios across cell types. Reports Cochran's Q for heterogeneity and I^2 statistic.

## Expression Stratification

### 5% Expression Proportion Filter
Isoforms must reach >= 5% of their gene's total CPM in at least one sample within the cell type to pass. This removes very low-abundance isoforms that contribute noise to association tests. Analyses are run both with and without this filter.

### DMSO Expression Tertiles
For logFC distribution analysis, isoforms are stratified into tertiles of mean DMSO CPM (Low, Mid, High) within each cell type. Zero-DMSO isoforms are handled separately (excluded in filtered analyses, shown as separate category in unfiltered).

## NMD Responsiveness Classification

An isoform is classified as NMD-responsive if:
- `adj.P.Val < 0.05` (FDR-corrected)
- `logFC > 0` (upregulated under Smg1i treatment)

This definition captures transcripts that are stabilized when NMD is inhibited.

## Frame Disruption Analysis

### Approach
For each splicing event between a dominant-comparator pair, the overlap with the **dominant isoform's** CDS is computed. Using the dominant's reading frame as reference avoids the circular problem of using each isoform's own CDS annotation.

### Frame-Disrupting Events
An event is frame-disrupting if:
1. It overlaps the dominant's CDS region
2. The CDS-overlapping portion is not divisible by 3

Event types assessed: SE, Missing_Internal, A5SS, A3SS, Partial_IR_5, Partial_IR_3.

### Direction-Based Analysis
LOSS events (comparator missing sequence relative to dominant) are analyzed separately, as these are most likely to introduce PTCs in the comparator. LOSS + frame-disrupting events represent cases where the comparator has a frameshift relative to the dominant's reading frame.

## Multiple Testing Correction

All per-cell-type p-values within an analysis are corrected using the Benjamini-Hochberg FDR method. The signal exploration script applies FDR correction across all tests within its comprehensive summary.

## Cell Types

Six cell types are analyzed: AT (Alveolar Type 2), DD (Differentiated), DD_ALI (Differentiated Air-Liquid Interface), DO (Donor), FB (Fibroblast), MV (Microvascular).
