**Supplemental Figure | Descriptive characterisation of the Isopair gene-matched isoform-pair set (pop_BC; 3,009 genes; 3,009 NMD pairs + 3,009 Control pairs).**

Three descriptive panels for the n = 3,009 gene-matched pair set used throughout §4 (Fig 3 / Fig 4).

**(A)** Distribution of expressed non-NMD isoforms per gene across the 3,009 genes in pop_BC. Counted as in the Isopair pipeline (`05_final_report_mashr.Rmd` §2): for each pair-gene, isoforms with a row in the TMM-normalized count matrix and not classified as NMD-sensitive (mashr `nmd_responsive == TRUE` across the 4-CT scope). Median = 7 (IQR = 5); 23.9% of genes have ≥ 10 expressed non-NMD isoforms. The 3,009-gene pair set comes from gene-matched (gene + reference isoform) intersection of the C2 (NMD) and C4 (Control) profiles (`profiles_c2_allsamples.rds`, `profiles_c4_allsamples.rds`).

**(B)** Distribution of the reference-isoform expression as a fraction of the parent gene's total non-NMD expression. Reference expression is the DMSO 4-CT (AT + DD + FB + MV) mean from the TMM-normalized count matrix; gene total is the sum of DMSO 4-CT means across all non-NMD expressed isoforms of the gene (same set as Panel A). Median reference share = 31%; 38% of references are above the 50% threshold (orange dotted line). The distribution is bimodal: many genes have a dominant reference isoform (right tail near 100%), but a substantial fraction of pair-genes have several comparably-expressed non-NMD isoforms with the highest-expressed one capturing only ~25–35% of total. (These two values are the ones cited in the revised §4¶1.)

**(C)** Transcript-length distribution by role within each pair (n = 3,009 NMD comparators in peach, 3,009 references in gray, 3,009 Control comparators in blue). Lengths are spliced transcript lengths (sum of exon lengths from `structures.rds`), not genomic span. Medians: NMD comparator 3,049 nt, reference 2,893 nt, Control comparator 2,762 nt — matching §4¶2 exactly. Pairwise Wilcoxon: NMD vs reference p = 3.4×10⁻², NMD vs Control p = 2.1×10⁻⁸, reference vs Control p = 7.9×10⁻⁴; Kruskal–Wallis p = 1.5×10⁻⁷. The 287-nt gap between NMD and Control comparators (median difference) is statistically detectable at this sample size but biologically modest. Violins show kernel-density estimates on the log-transformed length; solid bar marks the median, dotted bars q25 and q75. Stars: ****p < 10⁻¹⁰, ***p < 10⁻⁴, **p < 10⁻³, *p < 0.05, n.s. otherwise.

**Abbreviations.** pop_BC, the universe of gene-matched isoform pairs (NMD + Control arms) constructed by the Isopair pipeline; DMSO, vehicle (baseline) condition; TMM, trimmed mean of M-values (edgeR normalization); 4-CT, the four manuscript-scope cell types (AT, DD, FB, MV); IQR, interquartile range.
