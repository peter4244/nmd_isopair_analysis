**Supplemental Figure — Branch-level KernelSHAP stratified by PTC subclass across the full n = 1,166 ref-AUG-traceable subset.**

KernelSHAP attributions of the deep-learning model's NMD-call signal across its three input branches (AUG window, stop window, structural features), measured at the fusion-layer concatenation point of the trained NMD predictor (same source and methodology as **Figure 5 Panel C**). Three side-by-side mini-panels — one per PTC subclass within Subset 2 (the n = 1,166 ref-AUG-traceable gene-matched subset; same scope as Figure 4 C/D and Figure 5 Panel G). Subgroup counts: **NMD+/PTC+** n = 1,016, **NMD+/PTC− retained** n = 95, **Control** n = 1,107. Branch attribution covers the full subset; the figure is not test-set restricted. Each panel uses the Panel C styling convention: bars are ranked by importance within the subgroup (Structural / Stop / AUG); the percent above each bar is the within-subgroup share of total mean |SHAP|; the value inside each bar is the subgroup mean |SHAP|.

**(A)** NMD+/PTC+ retained (n = 1,016). Structural features dominate (61.9% of total branch attribution); the Stop branch carries 29.1%; the AUG branch only 9.0%. This pattern mirrors the pooled Figure 5 Panel C (Structural 60.7% / Stop 28.8% / AUG 10.5%) — when a real PTC is present, downstream-EJC signal and stop-window content are sufficient to drive the call. **(B)** NMD+/PTC− retained (n = 95). Structural branch share drops to 52.6% (loss of downstream-EJC count signal); Stop branch holds at 29.2%; **AUG branch share doubles to 18.1%**. Absolute Structural attribution drops from 2.28 to 0.99 — a >50% reduction in total branch signal — while absolute AUG attribution is essentially unchanged (0.33 → 0.34), so within these isoforms the AUG window carries a much larger share of the explanation. **(C)** Control (n = 1,107). Profile resembles NMD+/PTC+ in proportions (Structural 62.3% / Stop 27.1% / AUG 10.6%) but at much lower absolute magnitude — the model uses the same features but with consistently smaller attribution.

Headline ratio: the AUG branch contributes a **`r 18.1/9.0 ≈` 2.0-fold larger share** of the model's NMD-call signal in NMD+/PTC− isoforms than in NMD+/PTC+ isoforms (18.1% vs 9.0%). The manuscript prose reading "roughly three times more important" is **not supported at the n = 1,166 scope**; find/replace pair logged in the SF's README.md.

**Abbreviations.** SHAP, SHapley Additive exPlanation; PTC, premature termination codon; NMD, nonsense-mediated decay; AUG, methionine start codon; EJC, exon–exon junction complex.
