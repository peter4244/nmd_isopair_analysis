**SF29 | GAIN Direction by Splice Event Type.** Percentage of detected splice events (across 3,009 gene-matched isoform triplets, both NMD and Control comparators) in which the comparator has additional sequence relative to its reference isoform (GAIN direction). One bar-pair per event type — NMD comparators (orange) vs Control comparators (blue) — sorted by NMD-side %GAIN, descending. Dashed line, 50% (no directional preference). Direction is defined from the comparator's perspective (see SF24 for event-type definitions). Significance stars, Fisher's exact test on the 2 × 2 (GAIN/LOSS × NMD/Control) count table per event type.
