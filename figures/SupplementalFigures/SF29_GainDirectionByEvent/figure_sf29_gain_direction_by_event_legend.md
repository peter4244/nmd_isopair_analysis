**SF29 | Gain Direction by Splice Event Type.** Percentage of detected splice events (across 1,548 gene-matched isoform triplets, both NMD and Control comparators) in which the comparator has additional sequence relative to its reference isoform (Gain direction). One bar-pair per event type — NMD comparators (orange) vs Control comparators (blue) — sorted by NMD-side %Gain, descending. Dashed line, 50% (no directional preference). Direction is defined from the comparator's perspective (see SF24 for event-type definitions). Significance stars, Fisher's exact test on the 2 × 2 (Gain/Loss × NMD/Control) count table per event type: *p < 0.05, **p < 10⁻³, ***p < 10⁻⁴; n.s. otherwise.
