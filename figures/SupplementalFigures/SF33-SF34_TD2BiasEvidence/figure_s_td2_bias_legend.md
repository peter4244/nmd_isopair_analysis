**SF33 + SF34 | TD2 open-reading-frame length, start-codon position and Kozak strength versus reference-AUG-traced ORFs.**  Row 1 (n = 1,166 broad ref-AUG-traceable set) and row 2 (n = 492 hidden-PTC subset) together support SF33 (length + position panels) and SF34 (Kozak PWM panels).

Three orthogonal observations of the same systematic bias presented at two complementary cohorts (2×3 layout). The top row uses the 1,166-pair ref-AUG-traceable gene-matched cohort that supports Figure 4 Panels C and D; within this cohort the standard caller picked the same start codon as the reference in 50% of pairs (578 / 1,166) and a different start codon in 50% (588 / 1,166). The bottom row uses the hidden-PTC subset of the top row (n = 492) — pairs in which the reference-start projection revealed a downstream-junction stop indicative of a premature termination codon that the standard caller's own open reading frame had skipped over. The bias is most pronounced in the hidden-PTC subset by construction.

**(A, D) Open-reading-frame length.** Distribution of ORF length under the standard caller's chosen start codon (blue) versus under the reference start codon projected onto the same transcript (coral). The caller-selected ORF is ~5× longer than the reference-anchored ORF on the broad cohort (Panel A; medians 2,758 vs 588 nt) and ~8× longer on the hidden-PTC subset (Panel D; medians 2,934 vs 380 nt). The caller systematically picks longer reading frames that bypass the premature stop.

**(B, E) Kozak context.** Paired Kozak position-weight-matrix scores at the reference start codon versus at the standard caller's start codon, scored on the NMD-susceptible isoform. The reference start codon has systematically stronger Kozak context than the caller's pick on both the broad cohort (Panel B; paired Wilcoxon p = 1.2×10⁻³⁸; medians 0.86 vs 0.29; reference Kozak > caller Kozak in 446 of 1,166 pairs) and the hidden-PTC subset (Panel E; p = 2.6×10⁻³⁸; medians 1.04 vs −0.35; reference Kozak > caller Kozak in 384 of 492 pairs, i.e., 78% of pairs follow the bias direction).

**(C, F) Position of the caller's start codon relative to the reference.** Position in transcript coordinates with the reference start codon at 0 (red dashed line). On the broad cohort (Panel C) a large spike at 0 reflects the 50% of pairs in which the caller chose the same start codon as the reference; 43% of pairs (496 / 1,166) have the caller's start downstream (median offset +471 nt) and 8% (92 / 1,166) have it upstream. On the hidden-PTC subset (Panel F) the spike at 0 disappears: 99% (487 / 492) of caller starts are downstream of the reference (median offset +476 nt); only 1% (5 / 492) are upstream. The contrast between the two rows shows that the caller's start-codon disagreement with the reference is most extreme — and almost always in the downstream, premature-termination-codon-avoiding direction — in exactly the population where the bias is biologically engaged.
