**Figure S. Pair-analysis cohort flowchart.** Flow of the isoform-pair analyses, from the 4-cell-type starting cohort through the two subsets used in Figures 3, 4, and supplements. Every filter step shows the number of pairs kept and dropped, and a one-line description of why each dropout happened.

**Starting cohort and upstream steps (top column).** The flowchart begins with the manuscript-scope cohort — 26 samples (AT n = 6, DD n = 8, FB n = 6, MV n = 6) and 123,790 expressed isoforms. From this cohort each isoform is classified as NMD-sensitive or non-NMD-sensitive (per-cell-type + 4-CT-union mashr framework), and paired comparisons are constructed (per gene: the dominant NMD-sensitive isoform against a reference, together with two dominant non-NMD-sensitive isoforms — one as reference, one as Control). Before gene-matching this produces 3,009 NMD-sensitive pair candidates and 8,323 Control pair candidates.

**Matched isoform pairs (central navy box).** Pairs are then matched across the two arms so that each gene contributes a single triplet — one reference transcript, one NMD-sensitive comparator, and one Control comparator — yielding **3,009 NMD-sensitive pairs and 3,009 Control pairs**. This central cohort is the starting point for both downstream subsets.

**Subset 1 (left, orange cluster; n = 190).** The strictest cohort: all three transcripts of the triplet are annotated coding transcripts (in GENCODE, with a curated coding sequence). Two filters reduce the starting 3,009 to 190 pairs. The first filter — requiring all three transcripts to be annotated — drops 2,708 pairs because most NMD-sensitive transcripts are novel isoforms discovered by long-read sequencing and are absent from GENCODE. The second filter — requiring a curated coding sequence on all three — drops a further 111 pairs that are annotated but non-coding (lncRNA and similar). The NMD-sensitive comparator in each of the surviving 190 pairs is then classified by whether its own annotated stop codon sits more than 50 nt before the last exon-exon junction, a hallmark of nonsense-mediated decay substrates: 72 are PTC+ (38 %), 118 are PTC−, and the 190 Control comparators are not stratified by PTC status (PTC status is a property of the NMD-sensitive comparator). Subset 1 is consumed by Figure 3 Panels D / E / F, Figure 4 Panels A / B, and CDS / 3′UTR supplement Row 1.

**Subset 2 (right, blue cluster; n = 1,166).** Broader cohort that keeps pairs where the NMD-sensitive or Control comparator is novel, as long as the reference transcript is annotated and the reference start codon can be mapped onto the comparator. Three filters narrow the starting 3,009 to 1,166. Requiring the reference itself to be annotated drops 911 pairs whose reference is novel. Requiring that the genomic position of the reference start codon falls within an exon of the comparator drops a further 439 NMD-sensitive and 812 Control pairs whose comparator transcript is missing the relevant exon. Re-matching to keep only genes where this mapping succeeded on both arms drops 493 NMD-sensitive and 120 Control pairs, leaving 1,166 / 1,166. Each NMD-sensitive comparator is then classified by where the reference start codon — projected onto that comparator's transcript — leads: a premature stop versus an extended or matched ORF. 1,050 of 1,166 (90 %) carry a premature stop under this projection; 116 do not. Subset 2 is consumed by Figure 4 Panels C / D and CDS / 3′UTR supplement Row 2.

**Hidden-PTC sub-cascade (purple, off Subset 2; n = 492).** Sub-subset of Subset 2 in which the standard CDS caller (TD2; the program SQANTI3 uses to annotate novel isoforms) did not flag a premature stop, but the reference-anchored analysis did. 674 of the 1,166 Subset-2 pairs are dropped because there is either no premature stop at all or both methods agree. In the remaining 492 "hidden-PTC" pairs, TD2 has selected a coding sequence that starts downstream of the reference start codon — long enough to extend the ORF past the would-be premature stop into an in-frame coding region. The biological ribosome would in general initiate at the upstream reference start codon, so TD2's downstream call misses a real NMD substrate. This subset is the population in which TD2's PTC-avoidance bias is most pronounced and is consumed by the TD2 Bias Evidence supplement.

**Color coding.** Dark slate = upstream pipeline (raw matrix to pair construction). Yellow = NMD classification and per-subset PTC classification. Dark navy = central matched-pair hub. Orange cluster = Subset 1 (strict). Blue cluster = Subset 2 (broader). Purple = Hidden-PTC subset. Gray = downstream figure / supplement consumers. Cluster borders carry each subset's defining description as the cluster title.
