**Figure S. TransDecoder2 (TD2) systematically selects a downstream non-PTC ORF in place of the biologically authentic upstream reference AUG — most extreme in the occult-PTC subset where TD2's PTC-avoidance is operationally engaged.**

Three orthogonal observations of TD2's ORF-call behavior on the same isoform universe as Figure 4 Panels C and D, presented at two complementary scopes (2×3 layout). **Top row (Panels A–C; n = 1,166)** — 1:1 gene-matched NMD comparator pairs in the ref-AUG-traceable universe (matches Figure 4 Section C scope exactly: gene-matched NMD c2 ∩ GENCODE-annotated reference ∩ category ∈ {effectively_ptc, no_downstream_ejc, truncated_no_ejc} ∩ TD2 CDS available ∩ reference AUG exonic in comparator ∩ re-intersected on `(gene_id, reference_isoform_id)` with the Control side after the category filter). Within this universe, TD2 selected the same ATG as the reference AUG in 50% of pairs (578 / 1,166) and a different ATG in 50% (588 / 1,166). **Bottom row (Panels D–F; n = 492)** — the occult-PTC subset of the top row: pairs in which reference-AUG tracing revealed a downstream-EJC stop indicative of a premature termination codon that TD2's own CDS call missed (`effectively_ptc ∩ original_ptc == FALSE`, within the re-intersected universe). In this subset TD2 ATG ≠ ref AUG by construction; the bias is most pronounced.

**(A, D)** Distribution of ORF length under TD2's selected CDS (blue) vs the reference-AUG-anchored ORF (coral) on the same isoforms. TD2-selected CDS shifts ~4.7× longer than the reference-AUG-anchored ORF on the broad scope (Panel A; median 2,758 vs 588 nt) and **~7.7× longer** on the occult-PTC subset (Panel D; median 2,934 vs 380 nt). **(B, E)** Paired Kozak PWM scores at the reference AUG vs at the TD2-predicted ATG (scored in the NMD+ isoform context using `Isopair::scoreKozakPWM`). The reference AUG has systematically stronger Kozak sequence context than TD2's chosen ATG, on both the broad scope (Panel B; paired Wilcoxon p = 1.2×10⁻³⁸; medians 0.86 vs 0.29; reference Kozak > TD2 Kozak in **446 of 1,166 pairs (38.3%)** — including the 50% of pairs where TD2 chose the same start codon and the two scores are equal) and the occult-PTC subset (Panel E; **p = 2.6×10⁻³⁸**; medians 1.04 vs −0.35; reference Kozak > TD2 Kozak in **384 of 492 pairs (78.0%)** — i.e., 3 out of 4 pairs follow the bias direction). **(C, F)** Position of the TD2-selected ATG relative to the reference AUG in comparator transcript coordinates. The reference AUG is at 0 (red dashed line); the median downstream offset is marked with a dotted line. On the broad scope (Panel C) a large spike at 0 reflects the 50% of pairs where TD2 chose the same start codon as the reference; 43% (496/1,166) have TD2 downstream (median offset +471 nt) and 8% (92/1,166) have TD2 upstream. On the occult-PTC subset (Panel F) the spike at 0 disappears: **99.0% (487/492)** of TD2 ATGs are downstream of the reference AUG (median offset +476 nt); only 1.0% (5/492) are upstream. Together, the contrast between the broad and occult-PTC rows shows that TD2's start-codon disagreement with the reference is most extreme — and almost always in the downstream non-PTC-yielding direction — in exactly the population where TD2's PTC-avoidance behavior is biologically engaged.

**Abbreviations.** NMD, nonsense-mediated decay; PTC, premature termination codon; ORF, open reading frame; CDS, coding sequence; AUG, methionine start codon (RNA notation); ATG, methionine start codon (DNA notation); EJC, exon–exon junction complex; ENST, GENCODE/Ensembl transcript identifier prefix; TD2, TransDecoder2 (computational CDS predictor wrapped by SQANTI3); PWM, position-weight matrix (Kozak start-codon context score, log-odds); KDE, kernel density estimate.
