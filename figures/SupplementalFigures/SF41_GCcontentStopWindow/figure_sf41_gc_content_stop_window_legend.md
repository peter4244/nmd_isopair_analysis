**SF41 | Rolling GC Content Across the AUG and Stop-Codon Windows.** Mean rolling GC content per position of the input transcript sequences fed to the deep-learning model, comparing NMD-susceptible (orange) and Control (blue) transcripts on the held-out test cohort. Each transcript's window is centered on its priority ORF's start or stop codon; priority is reference-CDS ORF (ref-AUG traced from the gene's dominant non-NMD isoform) → TransDecoder2 CDS ORF → highest-Kozak-scoring ORF (see Methods, Priority ORF Selection). NMD-susceptible isoforms are restricted here to those whose priority ORF is the reference CDS (`is_ref_cds = 1`; n = 1,743 of 2,268 NMD test transcripts, 76.9%), so that "position 0" is the ref-AUG-traced true stop rather than a TransDecoder2 downstream stop; Control isoforms are unfiltered (n = 7,863). GC content is computed in a 50-nt sliding window with a 10-nt step from the model's one-hot nucleotide input channels; shading is ± 1 standard error of the mean. **A)** AUG window. **B)** Stop codon window.
