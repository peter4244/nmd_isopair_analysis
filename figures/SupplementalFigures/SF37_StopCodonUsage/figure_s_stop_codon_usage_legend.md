**SF37 | Stop-codon usage in NMD susceptible vs non-NMD isoforms.** Within-class frequency of the three canonical stop codons (UGA / UAA / UAG) at the main open reading frame of each transcript in the deep-learning model's held-out test set (n = 2,268 NMD susceptible, n = 7,863 non-NMD). Main open reading frames are chosen with the following priority: the annotated reference CDS (projected from the gene's dominant non-NMD isoform) when available; otherwise the TransDecoder2-called CDS; otherwise the highest-Kozak-scoring open reading frame (see Methods, Main open reading frame selection). Percentages: UGA 55.9 % vs 48.1 %; UAA 23.9 % vs 29.9 %; UAG 20.2 % vs 22.0 %.

Abbreviations. NMD, nonsense-mediated decay; UGA / UAA / UAG, the three canonical stop codons in RNA notation.
