**SF24 | Twelve Splice Event Categories Detected by Isopair.** Schematic of the twelve splice-event types Isopair identifies when comparing a paired isoform (Comparator, bottom, orange) to the gene's dominant non-NMD isoform (Reference, top, grey). Boxes represent exons; lines represent introns; positions are illustrative examples on the + strand (5′ → 3′, left → right). Categories: transcript-end variants (Alt TSS, Alt TES); alternative splice sites (A5SS, A3SS); exon skipping (Skipped Exon, Missing Internal); and intron retention in six forms (Partial IR 5′, Partial IR 3′, Full IR, IR diff 5′, IR diff 3′, IR diff 5′ + 3′). Every detected event set is validated by reconstruction: Comparator exons plus the detected events must exactly reproduce Reference exons. Coordinates match the canonical Event Type Glossary in the Isopair analysis Rmd.
