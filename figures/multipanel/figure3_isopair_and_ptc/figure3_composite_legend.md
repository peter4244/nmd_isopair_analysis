**Figure 3. Isopair gene-matched isoform-pair analysis identifies skipped exons and premature termination codons as the dominant drivers of NMD susceptibility.**

**(A)** Isopair construction: for each gene, an NMD pair contrasts the highest-expressed non-NMD reference isoform with an SMG1i-responsive comparator, and a Control pair contrasts the same reference with the next-most-expressed non-NMD comparator. 3,009 NMD and 3,009 Control pairs across 3,099 genes. **(B)** Density of exonic sequence shared between comparator and reference; NMD comparators share more sequence than Controls, consistent with NMD arising from targeted splicing. **(C)** Per-event-type prevalence; SE is twice as prevalent in NMD pairs (44.2 vs 21.2%, p ≈ 10⁻⁸¹). **(D)** Distance from each comparator's own GENCODE-annotated stop codon to its last exon–exon junction, restricted to pairs in which the reference, NMD comparator, and Control comparator are all GENCODE-annotated coding isoforms (n = 190 NMD, 190 Control). Positive = PTC direction; dashed line marks the 50-nt PTC threshold. **Direct PTC rate 37.9% NMD (72/190) vs 2.1% Control (4/190) — 18× enrichment.** **(E)** Proportion of each event type among Isopair-attributed PTC-causing events in NMD (coral; n = 69 attributed events from 72 PTC+ pairs) vs all events in 190 Controls (light blue; n = 447 total events). SE accounts for 43.5% of PTC-causing events vs 14.1% of Control events (Fisher p = 8×10⁻⁸); A5SS is enriched (13.0% vs 4.5%, p = 9×10⁻³); Alt TES is depleted (5.8% vs 26.8%, p = 3×10⁻⁵). **(F)** PTC-causing events stratified by mechanism: 69 attributed pairs split 38 frameshift (coral) / 23 in-frame stop (blue) / 8 3′UTR splice (teal) = 55% / 33% / 12%. Stars: ****p < 10⁻¹⁰, ***p < 10⁻⁴, **p < 10⁻³, *p < 0.05, n.s. otherwise (Fisher's exact).

**Abbreviations.** NMD, nonsense-mediated decay; PTC, premature termination codon; EJC, exon–exon junction complex; SMG1i, SMG1 kinase inhibitor; SE, skipped exon; A5SS / A3SS, alternative 5′ / 3′ splice site; IR, intron retention; Partial IR 5′/3′, partial intron retention at the 5′/3′ end; IR differs, intron retained in both isoforms with different boundaries; Missing internal, internal exon present in reference but absent in comparator; Alt TSS / TES, alternative transcription start / end site; TD2, TransDecoder2.
